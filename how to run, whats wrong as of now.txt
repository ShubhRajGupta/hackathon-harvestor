### How to Fix This

You have two choices to get your database running:

#### Option A: Start your local MongoDB service (If installed)
If you have MongoDB installed locally on your Windows machine, open PowerShell as an **Administrator** and start it:
```powershell
Start-Service -Name MongoDB
```
*(Alternatively, run `net start MongoDB` or run `mongod` in a separate command window).*

#### Option B: Use MongoDB Atlas (Cloud - Recommended & Easiest)
If you don't have MongoDB installed locally, you can use a free cloud database:
1. Go to [MongoDB Atlas](https://www.mongodb.com/atlas) and sign up for a free account.
2. Create a free M0 cluster.
3. In the Database Access settings, create a database user (e.g., username `admin` and a password).
4. In Network Access, allow access from anywhere (`0.0.0.0/0`) or add your current IP address.
5. Click **Connect** -> **Drivers** to get your connection string.
6. Open your [.env](file:///x:/Projects/harvester/hackathon-harvestor/.env) file and replace the `MONGODB_URI` with your connection string:
   ```env
   MONGODB_URI=mongodb+srv://admin:<password>@cluster0.xxxx.mongodb.net/
   ```
   *(Be sure to replace `<password>` with your database user password).*

---

Once the database is online, restart the application:
```powershell
python test/run.py
```
It will automatically trigger an initial scrape on startup, populate your database with active hackathons, and display them on the dashboard.
